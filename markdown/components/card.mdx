# 카드 (Card)

콘텐츠와 액션을 시각적으로 그룹화하는 유연한 서피스(Surface) 컨테이너입니다. 토스, 당근 등 설정된 디자인 가이드의 라운딩과 그림자 토큰이 자동 적용됩니다.

<Callout type="tip">
  카드는 상호작용 가능한 `.atom-card-interactive` 클래스를 통해 호버 시 부드러운 엘리베이션 리프트 애니메이션을 제공합니다.
</Callout>

## 🚀 멀티 프레임워크 사용법 (Multi-Framework Usage)

<FrameworkTabs 
  react={`import 'atomsystem/css/atom-ui.css';
import { Card, CardHeader, CardContent, CardFooter } from 'atomsystem';

export default function Demo() {
  return (
    <Card className="max-w-sm">
      <CardHeader>
        <h3 className="atom-title-2">송금 완료</h3>
        <p className="atom-caption">2026.10.01 17:00</p>
      </CardHeader>
      <CardContent>
        <p className="atom-body-1">성공적으로 50,000원이 전달되었습니다.</p>
      </CardContent>
    </Card>
  );
}`}
  vue={`<template>
  <div class="atom-card atom-card-interactive max-w-sm">
    <div class="atom-card-header">
      <h3 class="atom-card-title">당근 동네생활</h3>
      <p class="atom-card-subtitle">역삼동 · 3분 전</p>
    </div>
    <div class="atom-card-body">
      <p class="atom-body-2">근처에 맛있는 붕어빵 가게 찾았습니다!</p>
    </div>
  </div>
</template>`}
  vanilla={`<!-- 1. Pure HTML -->
<div class="atom-card atom-card-interactive" id="item-card">
  <div class="atom-card-header">
    <h3 class="atom-card-title">에어팟 프로 2세대 미개봉</h3>
    <p class="atom-card-subtitle">서초동 · 끌올 5분 전</p>
  </div>
  <p class="atom-title-2" style="color: var(--color-primary);">220,000원</p>
</div>

<!-- jQuery 클릭 이벤트 -->
<script>
  $('#item-card').on('click', function() {
    console.log('카드 상세 페이지로 이동');
  });
</script>`}
  angular={`import { Component } from '@angular/core';

@Component({
  selector: 'app-card-demo',
  standalone: true,
  template: \`
    <div class="atom-card max-w-md">
      <div class="atom-card-header">
        <h3 class="atom-card-title">{{ title }}</h3>
      </div>
      <p class="atom-body-1">{{ content }}</p>
    </div>
  \`
})
export class CardDemoComponent {
  title = '알림 카드';
  content = '새로운 메시지가 도착했습니다.';
}`}
/>
